1. Giới thiệu

Extension Live Event Translator giúp dịch âm thanh từ tab trình duyệt đang phát sự kiện thành giọng nói và phụ đề bằng Google Gemini Live Translate.

Chính sách này giải thích dữ liệu nào được xử lý khi bạn dùng extension, dữ liệu đó đi đâu, và cách bạn kiểm soát dữ liệu của mình.

2. Dữ liệu chúng tôi xử lý

Extension có thể xử lý các loại dữ liệu sau:

  • Gemini API key: do bạn nhập, lưu cục bộ trong chrome.storage.local trên trình duyệt của bạn.
  • Âm thanh tab: âm thanh từ tab bạn chọn khi bật dịch, dùng để gửi tới Gemini Live Translate.
  • Bản dịch / phụ đề: văn bản và âm thanh dịch được tạo ra trong phiên dịch; bạn có thể lưu file transcript trên máy.
  • Tuỳ chọn giao diện: vị trí overlay, độ trong suốt, và cài đặt làm mượt transcript — lưu cục bộ trên máy bạn.

Extension không thu thập tên, email, lịch sử duyệt web tổng quát, hay dữ liệu analytics của bên thứ ba.

3. Cách dùng dữ liệu

  • API key dùng để tạo token phiên và gọi Gemini Live Translate / làm mượt transcript.
  • Âm thanh tab chỉ dùng để dịch thời gian thực khi bạn bấm bắt đầu dịch.
  • Tuỳ chọn giao diện chỉ dùng để nhớ cách bạn sắp xếp overlay và panel.

Chúng tôi không bán dữ liệu của bạn và không dùng dữ liệu để quảng cáo.

4. Chia sẻ với bên thứ ba

Khi bạn bắt đầu dịch, âm thanh tab (và khi bật tính năng làm mượt, đoạn transcript) được gửi tới máy chủ của Google:

  • https://generativelanguage.googleapis.com/*

Việc xử lý dữ liệu tại Google tuân theo chính sách của Google / Gemini API. Extension không gửi dữ liệu tới máy chủ riêng của nhà phát triển extension cho mục đích dịch.

Bạn cần có API key từ Google AI Studio.

5. Lưu trữ & bảo mật

  • API key và tuỳ chọn UI được lưu trên thiết bị của bạn qua chrome.storage.local.
  • Extension không tải hoặc chạy mã JavaScript từ xa; mã nguồn nằm trong gói extension.
  • Bạn nên bảo vệ API key như mật khẩu và có thể xoá key bất cứ lúc nào trong Cài đặt / Options của extension.

6. Quyền của bạn

  • Không bắt đầu dịch nếu bạn không muốn gửi âm thanh tab tới Google.
  • Xoá API key đã lưu trong extension bất cứ lúc nào.
  • Gỡ cài đặt extension để xoá dữ liệu lưu cục bộ của extension.
  • Quản lý / thu hồi API key trên Google AI Studio.

7. Trẻ em

Extension không hướng tới trẻ em dưới 13 tuổi và không cố ý thu thập thông tin cá nhân từ trẻ em.

8. Thay đổi chính sách

Chúng tôi có thể cập nhật chính sách này khi extension thay đổi cách xử lý dữ liệu. Ngày “Cập nhật” ở đầu trang sẽ được chỉnh theo phiên bản mới. Việc tiếp tục sử dụng sau khi cập nhật đồng nghĩa bạn chấp nhận chính sách đã sửa đổi.

9. Liên hệ

1. Introduction

Live Event Translator translates audio from a browser tab that is playing a live event into speech and captions using Google Gemini Live Translate.

This Privacy Policy explains what data is processed when you use the extension, where that data goes, and how you can control it.

2. Data we process

The extension may process the following:

  • Gemini API key: entered by you and stored locally in chrome.storage.local on your browser.
  • Tab audio: audio from the tab you select when you start translation, sent to Gemini Live Translate.
  • Translation / captions: translated text and speech generated during a session; you may optionally save a transcript file on your device.
  • UI preferences: overlay position, opacity, and transcript-polish settings — stored locally on your device.

The extension does not collect your name, email, general browsing history, or third-party analytics data.

3. How we use data

  • Your API key is used to mint a short-lived session token and call Gemini Live Translate / optional transcript polishing.
  • Tab audio is used only for real-time translation after you explicitly start translation.
  • UI preferences are used only to remember how you arrange the overlay and panel.

We do not sell your data and do not use it for advertising.

4. Third-party sharing

When you start translation, tab audio (and, if enabled, transcript text for polishing) is sent to Google’s servers at:

  • https://generativelanguage.googleapis.com/*

Google’s processing of that data is governed by Google / Gemini API terms and policies. The extension does not send translation data to a developer-operated backend.

You need an API key from Google AI Studio.

5. Storage & security

  • Your API key and UI preferences are stored on your device via chrome.storage.local.
  • The extension does not load or execute remote JavaScript; all extension code ships in the packaged extension.
  • Treat your API key like a password. You can delete it at any time in the extension Settings / Options page.

6. Your choices

  • Do not start translation if you do not want tab audio sent to Google.
  • Delete the saved API key in the extension at any time.
  • Uninstall the extension to remove its locally stored data.
  • Manage or revoke your API key in Google AI Studio.

7. Children

This extension is not directed at children under 13 and does not knowingly collect personal information from children.

8. Policy changes

We may update this policy when the extension’s data practices change. The “Last updated” date at the top of this page will reflect the latest version. Continued use after an update means you accept the revised policy.

9. Contact

For privacy questions about this extension, contact the developer through the support channel published with the Chrome Web Store listing or the project repository where you obtained the extension.
